WhatsApp Suite — Helpdesk Bridge

Connect your WhatsApp conversations to Odoo Helpdesk. A lightweight add-on for WhatsApp Suite (WAHA) that turns chats into support tickets.

🎫 Tickets from WhatsApp

Create or link a Helpdesk ticket from any incoming WhatsApp message in one click, or automatically via an auto-reply rule.

🔗 Smart button on tickets

Every ticket shows a WhatsApp smart button with the message count and opens the full conversation.

⚡ Auto-installs

Installs automatically once both WhatsApp Suite and Helpdesk (Enterprise) are present. Keeps the main app installable without Enterprise.

Requirements

  • The WhatsApp Suite (WAHA) app (sold separately).
  • Odoo Helpdesk (Enterprise).
